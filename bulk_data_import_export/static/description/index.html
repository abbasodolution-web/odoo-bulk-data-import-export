Bulk Data Import / Export

Import and export any model, fast, even with millions of rows and messy files

Odoo's standard import stops at the first problem and makes you fix the whole file before anything is saved. This module saves every good row, sets the bad ones aside, and gives you an Excel file of the failed rows with the reason next to each one. Fix them and import that same file again.

How it works

1. Upload an Excel or CSV file: columns are matched to fields automatically

2. The import runs in chunks; bad rows are set aside with the reason

3. Failed rows come back as Excel: fix them and import the same file again

4. Export any model to Excel or CSV, with External IDs for round trips

Import

  • Any model: contacts, products, sale orders with lines, custom models.
  • Excel or CSV (.xlsx, .xls, .csv); columns are matched to fields automatically by technical name or label.
  • Bad rows never stop the import: each failing row is isolated, everything else is saved.
  • Error report: an Excel file of the failed rows, the original cells plus the reason. Re-importable as is.
  • Chunks: rows are saved in chunks (500 by default). Big files run in the background, survive restarts, can be cancelled and resumed where they stopped.
  • Create, update or both: match existing records by any field (reference, email, barcode...), External ID or database ID.
  • Empty cells keep current values on update instead of clearing them (optional).
  • Test run: check a whole file without saving anything.
  • Template: download an Excel template with the required columns and a sheet describing every field.

Export

  • Any model, filtered with Odoo's domain editor, to Excel or CSV.
  • Streams records in chunks with flat memory use; large exports run in the background.
  • External ID column and linked records as External IDs: edit the file and import it back to update the same records, or move data to another database.

Built for speed

  • Uses Odoo's own loader, with chatter tracking switched off during the import.
  • Linked values ("Pakistan", "Pcs") are looked up once per chunk, not once per row.
  • Once a file shows errors, each chunk is checked before saving, so bad rows cost no extra save.
  • Errors that can't be tied to a row are found by splitting the chunk in halves, so only a few extra saves are needed.
  • Access rights and record rules of the user who started the job always apply.

No extra apps needed: depends only on Odoo's base, web and bus modules.

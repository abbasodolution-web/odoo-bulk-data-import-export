Import and export any model, fast, even with millions of rows and messy files

Import

Imports that do not give up

✓
Any model
Contacts, products, sale orders with lines, custom models.
✓
Excel or CSV
(.xlsx, .xls, .csv); columns are matched to fields automatically by technical name or label.
✓
Bad rows never stop the import
Each failing row is isolated, everything else is saved.
✓
Error report
An Excel file of the failed rows, the original cells plus the reason. Re-importable as is.
✓
Chunks
Rows are saved in chunks (500 by default). Big files run in the background, survive restarts, can be cancelled and resumed where they stopped.
✓
Create, update or both
Match existing records by any field (reference, email, barcode...), External ID or database ID.
✓
Empty cells keep current values
On update instead of clearing them (optional).
✓
Test run
Check a whole file without saving anything.
✓
Template
Download an Excel template with the required columns and a sheet describing every field.
Export

Export any model

✓
Any model, filtered with Odoo's domain editor, to Excel or CSV.
✓
Streams records in chunks with flat memory use; large exports run in the background.
✓
External ID column and linked records as External IDs: edit the file and import it back to update the same records, or move data to another database.
Performance

Built for speed

✓
Uses Odoo's own loader, with chatter tracking switched off during the import.
✓
Linked values ("Pakistan", "Pcs") are looked up once per chunk, not once per row.
✓
Once a file shows errors, each chunk is checked before saving, so bad rows cost no extra save.
✓
Errors that can't be tied to a row are found by splitting the chunk in halves, so only a few extra saves are needed.
✓
Access rights and record rules of the user who started the job always apply.
Installation

Install in 3 steps

1
Get the app
Click Download on this page (free).
2
Add it to Odoo
Unzip it into your custom add-ons folder (a folder listed in addons_path) and restart Odoo. On Odoo.sh, push the folder to your repository instead.
3
Install it
Turn on developer mode, open Apps › Update Apps List, search Bulk Data Import / Export and click Activate.
How to use

Import a file

1
Start an import
Open the Import / Export app › Imports › New, choose the model (Contacts, Products, Sales Orders...) and upload your Excel or CSV file.
2
Check the columns
Columns are matched to fields automatically. Fix any column that was matched wrong, choose create, update or both, and the field that finds existing records (reference, email, barcode, External ID...).
3
Run it
Good rows are saved in chunks; bad rows are set aside with the reason. Big files run in the background.
4
Fix the failed rows
Download the error report (Excel), correct the rows and import that same file again.
5
Export
Import / Export › Exports: pick a model, filter the records, choose the fields and download Excel or CSV.

Good to know

Does it work on Odoo Online (SaaS)?
No. Odoo Online does not allow apps from the store. It works on Odoo.sh and on your own server, Community or Enterprise.

Which models can I import?
Any model: contacts, products, sales orders with lines, custom models.
Do access rights still apply?
Yes. The access rights and record rules of the user who started the job always apply.

Yes. Versions for Odoo 18, 19 and 20 add preview, one-click undo, lines from a second sheet, saved mappings, scheduled exports, Check File and Dry Run.
